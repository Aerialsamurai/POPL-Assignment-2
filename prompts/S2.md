S2-1 — List helpers
Using the scheme-dev skill, implement tail-recursive `my-length`, `my-reverse`, and `my-map` using named let. They must work safely with lists of 10,000 elements. Only these definitions.

S2-2 — Nested insertion
Implement `(insert-if-short x lst n)` using `my-length` and `my-map`. Recursively visit nested lists and insert x at the front of each list whose original length is strictly less than n. Empty lists count as lists; dotted pairs are not used. Base decisions on the list's original length.

S2-3 — Input/output and higher-order inserter
Implement `(print-insert-result)` reading x, lst, and n in that order using `read` and `let*`, then printing the result and newline with no prompt. Implement `(make-inserter x len-ok?)`, returning a function that inserts x into each nested list whose original length satisfies `len-ok?`. Redefine `insert-if-short` using `make-inserter` so only one final definition remains.

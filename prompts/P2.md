P2-1 — Expression helpers
Using the prolog-dev skill, implement `op_prec/2` (+ and - precedence 1; * and / precedence 2), and `apply_op(Op,A,B,V)`. Division must succeed only if the divisor is nonzero and the division is exact, using `//`. Also implement `wrap_left/4` and `wrap_right/4`: wrap the left operand only when its precedence is lower than the parent; wrap the right operand when its precedence is equal or lower. Numbers have precedence 3 and are never wrapped. Use `format(string(_),...)` for strings.

P2-2 — Expression generation and equations
Implement `split/3` to split a list into two non-empty parts. Implement `expr(+Nums,-Str,-Val,-Prec)` to generate each expression using all numbers once, in original order, exactly once; return its canonical string, integer value, and top-level precedence. Build expression values recursively—do not parse strings. Implement `equation(List,Eq)` by trying every split, calculating right-side values once with `findall/3`, then matching left-side expressions and returning `L=R`. Implement `generate_equation/2` using `once/1`, safely failing for empty/singleton input or when no equation exists.
